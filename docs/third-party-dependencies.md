# Third-Party Dependencies

The project uses third-party libraries and runtime components referenced by packages.config.

Notable dependencies include EPPlus, iTextSharp, Microsoft ReportViewer, Microsoft.SqlServer.Types, System.Data.SqlClient, and System.IO.Ports.

Each dependency remains subject to its own license and terms. Consult the package metadata and upstream documentation before redistributing third-party components.

The project portfolio notice does not grant additional rights over third-party libraries.

# Third-Party Dependencies

The project uses third-party libraries and runtime components referenced by packages.config.

Notable dependencies include EPPlus, Microsoft ReportViewer, Microsoft.SqlServer.Types, System.Data.SqlClient, and System.IO.Ports. PDF export in the current application uses Microsoft Excel automation rather than iTextSharp.

Each dependency remains subject to its own license and terms. Consult the package metadata and upstream documentation before redistributing third-party components. EPPlus licensing should be reviewed before commercial or production use.

The project portfolio notice does not grant additional rights over third-party libraries.
